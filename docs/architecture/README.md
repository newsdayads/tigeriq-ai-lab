## Core Principles (Derived from Video Lessons)
- **Durable Resume**: Ensuring workflows and tasks can be reliably resumed from last known good state after interruption.
- **Knowledge Index**: Centralized indexing for fast context retrieval and architecture insights.
- **Orchestration Visibility**: Complete transparency and telemetry into multi-step execution flows.
