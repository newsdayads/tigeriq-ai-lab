## Overview
Convert recurring failures into durable rules, checks or skills with evidence. Automatically capture error signatures, deduplicate candidates, track provenance, and enforce registry governance.

## Operational Principles
1. **Capture & Signature**: Hash distinct error codes and task contexts to build unique failure signatures.
2. **Deduplication**: Prevent redundant candidate entries by checking existing registry items.
3. **Provenance Tracking**: Associate every candidate with verified batches, source logs, and structured evidence.
4. **Registry Governance**: Govern state transitions (CANDIDATE, VALIDATED, ACTIVE, DEPRECATED, REJECTED) reliably.
