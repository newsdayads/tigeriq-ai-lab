## Runtime status semantics
- IDLE = ONLINE and available, shown as RẢNH.
- BUSY = currently executing a job, job id visible.
- READY = credential/config available but not recently live-probed.
- RATE_LIMITED = quota/rate limit cooldown.
- WAIT_KEY = credential not yet available.
- ERROR/OFFLINE = failed/unavailable; Core re-probes after cooldown rather than continuously consuming quota.
