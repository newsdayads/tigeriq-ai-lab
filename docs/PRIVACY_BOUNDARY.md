# TigerIQ AI Lab — Repository Privacy Boundary

## General repository allowed
- Company Constitution
- Workflow/SOP
- AI Employee/Department Model
- Decision Log entries that contain no restricted personal data
- Architecture, ADRs, Work Orders, CURRENT_STATE, CI/test/review/deployment evidence

## Restricted/private — do not commit here
- `04_TIGERIQ_OWNER_PROFILE_v1.md`
- Health/medical information
- Intimate family information
- Authentication credentials, tokens, passwords, private keys
- Unnecessary personal identifiers
- Other sensitive personal data not explicitly required by a controlled business process

If a task requires restricted information, keep it in an access-controlled/private context and reference only the minimum non-sensitive facts required by the engineering work.
