## Actual changes
- **F07/F10:** Assignable QuickBar launch requests a bounded right-hand Android external-app frame using `ActivityOptions.launchDisplayId` and `launchBounds` only if `DexUtils.resolveDisplay` confirms **native Samsung DeX** and a valid external screen. Density comes from that exact display. In phone mode use normal Android launch; when DeX is claimed without a resolvable external screen, fail visibly. Bounds are requests subject to Android/OEM; no control over other applications, no simulated DeX acceptance.
- **F10:** `<queries>` for `ACTION_MAIN`/`CATEGORY_LAUNCHER` to find installed package launch targets on Android 11+; **no `QUERY_ALL_PACKAGES`**, no elevated runtime rights.
- **F04:** All four HOME Camera entry points (custom QuickBar `@camera`, narrow UI action, bottom transparent action and settings action) call the existing `UsbCameraActivity.toggleFromShortcut(this, requestedCameraDisplayId())` so actual display affinity and camera launch bounds are requested uniformly.
- **F03:** Camera entry *without existing CAMERA grant* shows `Chạm CAM để cấp quyền CAMERA và mở Camera USB UVC` and does not open an OS permissions dialog merely on viewing the frame; an explicit user press on `CAM` still requests Android permission. If CAMERA was already granted, existing automatic real UVC controller startup remains. Resumption of a previously open camera also fails visibly if the grant was revoked.
